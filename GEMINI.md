
Los archivos `GEMINI.md` son archivos markdown especiales que puedes crear dentro de tu proyecto para proporcionarme contexto e instrucciones específicas del proyecto.

Así es como personalizan nuestras interacciones:

*   **Conocimiento específico del proyecto:** Puedes incluir detalles sobre la arquitectura de tu proyecto, las convenciones de codificación, las bibliotecas preferidas o cualquier otra información que me ayude a comprender mejor el código base.
*   **Instrucciones automatizadas:** Puedes definir comandos para construir, probar, linting o desplegar tu proyecto. Esto me permite usar automáticamente los comandos correctos al realizar tareas como verificar cambios.
*   **Comportamiento personalizado:** Al proporcionar este contexto, puedo adaptar mi comportamiento para que coincida con las necesidades y convenciones específicas de tu proyecto, lo que lleva a una asistencia más precisa y eficiente.

En esencia, un archivo `GEMINI.md` actúa como una guía para mí, ayudándome a trabajar de manera más efectiva dentro del entorno específico de tu proyecto.
